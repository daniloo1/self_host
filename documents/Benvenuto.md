# Benvenuto nel tuo Archivio Documenti

Questo è un file di esempio in formato **Markdown** (compatibile con le note **Obsidian**).

## Cosa puoi fare qui
- Leggere note `.md` (inclusi link tra note nella stessa cartella come [[Benvenuto]])
- Leggere file di testo `.txt`
- Visualizzare documenti `.pdf` direttamente nella pagina, senza scaricarli sul PC remoto
- Scaricare un file solo quando clicchi su **Scarica**

Per aggiungere i tuoi documenti, mettili nella cartella `documents/` oppure usa il pulsante **+ Carica** in alto a sinistra.
